# Student Exam Score and Attendance Correlation Study

## 📊 Project Overview
This dashboard enables users to:
- Analyze the correlation between attendance and exam scores
- Monitor student academic performance using KPIs
- Identify top-performing students and subjects
- Compare performance based on gender and study hours
- Discover trends and patterns through interactive charts and visuals
---


## Project Objectives

1. To analyze the relationship between student attendance and exam performance.

2. To identify factors that influence academic success, such as study hours and attendance percentage.

3. To visualize student performance data using interactive Power BI dashboards and charts.

4. To compare subject-wise and gender-wise academic performance of students.

5. To generate meaningful insights and trends that can help improve student outcomes.

6. To apply data analytics techniques such as data cleaning, EDA, KPI analysis, and dashboard creation on real-world educational data.

## 📈 Dashboard Features

The Power BI dashboard includes the following visualizations:

- Interactive Power BI dashboard for student performance analysis
- Attendance vs Exam Score correlation analysis
- KPI cards showing:
  - Average Score
  - Attendance Percentage
  - Pass Percentage
  - Highest Score
- Subject-wise performance visualization
- Gender-wise student performance analysis
- Study Hours vs Exam Score insights
- Top 5 performing students analysis
- Dynamic filters and slicers for interactive exploration
- Clean and user-friendly dashboard design
- Data cleaning and preprocessing for accurate analysis
- Visual insights using charts and graphs
- Academic performance trend analysis
- Insight generation for improving student performance
---

## 🔍 Key Insights

* Students with **attendance above 80%** tend to score higher marks.
* Students with **attendance below 50%** are more likely to fail.
* Certain subjects show **lower average marks**, indicating higher difficulty.
* Early identification of **at-risk students** can help improve academic support.
